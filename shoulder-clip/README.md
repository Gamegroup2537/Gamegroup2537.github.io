# shoulder-clip

คลิปอธิบายความรู้แนวตั้ง 32 วินาที "อยากไหล่กลม ทรงสวย ต้องฝึกท่าไหน?" สไตล์พิกเซลอาร์ต 3D
ภาพ ข้อความ และเสียงทั้งหมดสร้างจากโค้ด ไม่มีไฟล์วิดีโอหรือเสียงจากภายนอก

ผลลัพธ์: `out/shoulder-clip.mp4` (1080×1920, 30 fps, H.264 + AAC, วนลูปได้)

## สร้างคลิปใหม่

**Windows แบบง่ายที่สุด:** ดับเบิลคลิก `build-clip.bat` ในโฟลเดอร์นี้ จะดึงรุ่นล่าสุด เรนเดอร์ด้วยการ์ดจอ แล้วเปิดคลิปให้เอง

ต้องมี Node.js 18 ขึ้นไป และ ffmpeg (Windows: `winget install OpenJS.NodeJS.LTS` และ `winget install Gyan.FFmpeg` แล้วเปิดหน้าต่างคำสั่งใหม่)

```bash
npm install
npm run build:gpu        # ใช้การ์ดจอของเครื่อง (เร็ว) จะเปิดหน้าต่าง Chrome หรือ Edge ขึ้นมาระหว่างเรนเดอร์
npm run build            # ไม่มีการ์ดจอ: เรนเดอร์ด้วย CPU (ช้า ราว 50 นาที)
npm run build:hud        # แก้แค่ข้อความ/กราฟิกบนจอ: ใช้เฟรม 3D เดิม วาดเฉพาะแผงข้อมูลใหม่
npm run preview -- 0 180 369   # ดูเฟรมที่ต้องการเป็น PNG ใน build/preview/
```

บน Windows PowerShell ถ้าขึ้นว่า `npm.ps1 cannot be loaded because running scripts is disabled` ให้พิมพ์ `npm.cmd` แทน `npm` (เช่น `npm.cmd run build:gpu`)

ผลลัพธ์อยู่ที่ `out/shoulder-clip.mp4` ตอนเริ่ม โปรแกรมจะพิมพ์บรรทัด `graphics: ...` บอกว่ากำลังใช้การ์ดจอตัวไหน

ถ้า `build:gpu` ค้างที่เฟรมแรกนานเกินไปหรือภาพผิดปกติ ลองเปลี่ยนตัวขับกราฟิก: `npm run build:gpu -- --angle=gl` (หรือ `d3d11`, `vulkan`) และเลือกเบราว์เซอร์ได้ด้วย `--browser=msedge`

เปิด `index.html?play` ผ่านเว็บเซิร์ฟเวอร์ใดก็ได้เพื่อดูแอนิเมชันสดในเบราว์เซอร์

## โครงสร้าง

| ไฟล์ | หน้าที่ |
|---|---|
| `src/timeline.js` | แหล่งความจริงเดียว: ท่าทาง การทำงานของกล้ามเนื้อ กล้อง คำบรรยาย ป้ายชี้ คำเน้น ป้ายตอน |
| `src/body.js` | ตัวแบบทั้งหมด (ผิว โครงกระดูก กล้ามเนื้อ เดลทอยด์ 3 มัด ดัมเบล) เป็น signed-distance field ชุดเดียว ray-march ทีละพิกเซลและลงแสงเงาแบบเดียวกันทุกชั้น กล้ามเนื้อแต่ละมัดวิ่งจากจุดเกาะต้นไปจุดเกาะปลายบนกระดูก |
| `src/scene.js` | เวที กล้อง ประกายไฟ และรอบวาดเส้นขอบ (ขอบแสงรอบตัวแบบ + ขอบสีของเดลทอยด์มัดที่ทำงาน) |
| `src/hud.js` | แผงข้อมูลบนจอ: แถบกล้ามเนื้อพร้อมแสงเรือง ตัวจับค่าสูงสุดและประกายไฟ, จอสัญญาณกล้ามเนื้อแบบเลื่อน, มาตรวัดมุมแขน, กราฟเรดาร์สรุป, คำบรรยาย ป้ายชี้ และคำเน้น |
| `src/main.js` | พื้นหลังและการรวมเลเยอร์ |
| `tools/render.mjs` | เรนเดอร์ทีละเฟรมแบบ deterministic ด้วย Playwright |
| `tools/audio.mjs` | สังเคราะห์เพลง chiptune และเสียงเอฟเฟกต์เป็น WAV |
| `tools/build.sh` | รวมเฟรมกับเสียงเป็น MP4 ด้วย ffmpeg |

## ปรับแต่ง

- ข้อความบนจอ: `CAPTIONS`, `LABELS`, `CALLOUTS`, `CHAPTERS` ใน `src/timeline.js`
- ลายน้ำชื่อช่อง: ตั้งค่า `WATERMARK` ใน `src/timeline.js`
- สีของแต่ละมัดกล้ามเนื้อ: `HEADS` ใน `src/timeline.js`
- รูปลักษณ์ เลือกผ่านตัวแปร `QUERY` ตอนเรนเดอร์ เช่น `QUERY="font=Mitr&smooth=1&motion=2" npm run build`
  - `font`: Kanit (ค่าเริ่มต้น), Prompt, Mitr, IBM Plex Sans Thai, Chakra Petch
  - `smooth`: `1` = ตัวอักษรคมชัด, ไม่ใส่ = ตัวอักษรแบบพิกเซล
  - `motion`: `0` ปรากฏทันที, `1` พิมพ์ทีละตัว (ค่าเริ่มต้น), `2` สไลด์เด้ง, `3` กลิตช์
  - `pix`: ขนาดพิกเซลของภาพ 3D (ค่าเริ่มต้น 3)
